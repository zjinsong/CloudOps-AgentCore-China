## 必须做的真实部署验收

本仓库独立版没有为发布而创建新云资源。原应用已在宁夏运行，并验证平台 V2；新的初始化脚本、Secret 注入、精简权限和全新账号组合尚未端到端云测。

读者部署时逐项确认：基础资源归属与 TTL；八个 Lambda/Target READY；六个 Runtime READY 和 DEFAULT 版本；EC2 IMDS 凭证；应用登录；简单专家查询；三专家协作；任务重启恢复；观测日志与调用链；权限拒绝写操作；清理和账单。

可用 `scripts/validate_cloud.py` 做服务配置检查，再做业务测试。失败报告应只提交脱敏错误与步骤，不提交私有状态文件。

## 明确未包含

企业 SSO/租户级 AWS 权限隔离、完整自动答案评估、Terraform 执行角色初始化、SQS 部署、托管长期记忆、Codex/Browser/Sandbox 工作区均不在默认部署里。

这个边界用于区分可运行核心、可选扩展和实施规划，避免把文档中的建议当作已经完成的功能。
